# «اِسْمَعْ» (علامتُها `Listen!`) — عائلة تطبيقات التأسيس

سادسُ العائلة (المسار «ب» مع «احسب»)، لتعليم الإنكليزية لطفلٍ عربيٍّ في السادسة.
**الاسمُ عربيٌّ حيث يُكتب نصّ، والعلامةُ المرسومة `Listen!` حيث تُرسَم علامة**
(أحكامُ المالك، ١٦ أغسطس ٢٠٢٦ — `docs/REVIEW_IDENTITY.md`). والمستودعُ يبقى
`english`: طبقةٌ تقنية لا يراها طفل.

ابدأ من `CLAUDE.md` (حالة المشروع وبوّابتاه)، ثم `docs/METHOD.md` (المنهج الملزم)
و`docs/SESSIONS.md` (بنود الجلسات ومحاضرها).

**والنشر**: `app/` وحدَه هو الموقع (`.github/workflows/pages.yml` عند الدفع إلى
`main`)، والنطاقُ `listen.mishkat.qa` مكتوبٌ في `app/CNAME` لا في لوحة إعدادات.
والمرجعُ التعريفيّ لوليّ الأمر والمعلّم في `app/welcome/` — **خارج قشرة عامل
الخدمة وبصفر جافاسكربت**. وبعد كل نشرة: `python3 tools/check_live.py`.
